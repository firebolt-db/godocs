# Contributing to Documentation

Learn how to contribute to Firebolt's documentation with these comprehensive guides.

## Getting Started

Before contributing, make sure you have:
- Repository access and local development environment set up
- Understanding of Mintlify documentation format
- Familiarity with the validation system
