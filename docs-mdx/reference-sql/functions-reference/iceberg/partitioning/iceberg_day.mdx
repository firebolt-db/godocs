Extracts the day from a date or timestamp value and returns it as the number of days since 1970-01-01, according to the [Iceberg partition transforms specification](https://iceberg.apache.org/spec/#partition-transforms).

## Syntax

```sql
ICEBERG_DAY(<value>)
```

## Parameters

| Parameter | Description | Supported input types |
|:----------|:------------|:----------------------|
| `<value>` | The date or timestamp value to extract the day from. | `DATE`, `TIMESTAMP`, `TIMESTAMPTZ` |

## Return type

`INTEGER`

Returns the number of days since 1970-01-01. For dates before 1970-01-01, returns a negative value.

## Examples

### Basic usage with dates

```sql
SELECT 
  iceberg_day('2025-12-15'::DATE) AS day_2024_03_15,
  iceberg_day('1970-01-01'::DATE) AS day_1970_01_01,
  iceberg_day('1969-12-31'::DATE) AS day_1969_12_31;
```

**Returns:**

| day_2024_03_15 | day_1970_01_01 | day_1969_12_31 |
|:---------------|:---------------|:---------------|
| 20437 | 0 | -1 |

### Usage with timestamps

```sql
SELECT 
  iceberg_day('2025-12-15 14:30:00'::TIMESTAMP) AS ts_day,
  iceberg_day('2025-12-15 14:30:00+00:00'::TIMESTAMPTZ) AS tstz_day;
```

**Returns:**

| ts_day | tstz_day |
|:-------|:---------|
| 20437 | 20437 |

### Historical dates

```sql
SELECT 
  iceberg_day('1900-12-31'::DATE) AS day_1900,
  iceberg_day('1971-01-01'::DATE) AS day_1971;
```

**Returns:**

| day_1900 | day_1971 |
|:---------|:---------|
| -25203 | 365 |

### Handling NULL values

```sql
SELECT iceberg_day(NULL::DATE) AS null_result;
```

**Returns:**

| null_result |
|:------------|
| NULL |
