Extracts the year from a date or timestamp value and returns it as the number of years since 1970, according to the [Iceberg partition transforms specification](https://iceberg.apache.org/spec/#partition-transforms).

## Syntax

```sql
ICEBERG_YEAR(<value>)
```

## Parameters

| Parameter | Description | Supported input types |
|:----------|:------------|:----------------------|
| `<value>` | The date or timestamp value to extract the year from. | `DATE`, `TIMESTAMP`, `TIMESTAMPTZ` |

## Return type

`INTEGER`

Returns the number of years since 1970. For dates before 1970, returns a negative value.

## Examples

### Basic usage with dates

```sql
SELECT 
  iceberg_year('2024-03-15'::DATE) AS year_2024,
  iceberg_year('1970-01-01'::DATE) AS year_1970,
  iceberg_year('1969-12-31'::DATE) AS year_1969;
```

**Returns:**

| year_2024 | year_1970 | year_1969 |
|:----------|:----------|:----------|
| 54 | 0 | -1 |

### Usage with timestamps

```sql
SELECT 
  iceberg_year('2024-03-15 14:30:00'::TIMESTAMP) AS ts_year,
  iceberg_year('2024-03-15 14:30:00+00:00'::TIMESTAMPTZ) AS tstz_year;
```

**Returns:**

| ts_year | tstz_year |
|:--------|:----------|
| 54 | 54 |

### Handling NULL values

```sql
SELECT iceberg_year(NULL::DATE) AS null_result;
```

**Returns:**

| null_result |
|:------------|
| NULL |
