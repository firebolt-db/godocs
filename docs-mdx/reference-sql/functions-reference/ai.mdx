## AI functions

AI functions invoke large language models (LLMs) and return their responses. Use a [`LOCATION`](/guides/security/location) to supply provider credentials and pass model-specific request payloads as JSON.

For a step-by-step introduction and examples, see [Getting started with AI](/guides/ai/getting-started-with-ai).

```sql
SELECT AWS_BEDROCK_AI_QUERY(
  'amazon.nova-micro-v1:0',
  '{"schemaVersion":"messages-v1","messages":[{"role":"user","content":[{"text":"Hello"}]}]}',
  'my_bedrock_location'
) AS result;
```
