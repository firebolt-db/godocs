Creates a new location object in your Firebolt account for Databricks. A Databricks `LOCATION` securely stores OAuth credentials and workspace details that you can reuse when invoking Databricks serving endpoints with [`DATABRICKS_AI_QUERY`](/reference-sql/functions-reference/ai/databricks-ai-query).

## Syntax

```sql
CREATE LOCATION [ IF NOT EXISTS ] <location_name> WITH
  SOURCE = DATABRICKS
  WORKSPACE_INSTANCE = '<workspace_instance>'
  CREDENTIALS = (
    OAUTH_CLIENT_ID = '<client_id>'
    OAUTH_CLIENT_SECRET = '<client_secret>'
    [ OAUTH_SCOPE = '<oauth_scope>' ]
    [ OAUTH_SERVER_URL = '<oauth_server_url>' ]
  )
  [ DESCRIPTION = '<description>' ];
```

## Parameters

### Common parameters

| Parameter | Description |
| :-------- | :---------- |
| `<location_name>` | A unique identifier for the location within your account. |
| `SOURCE` | The external source type. For Databricks, set to `DATABRICKS`. |
| `DESCRIPTION` | Optional comment describing the location's purpose. |

### Databricks parameters

| Parameter | Description |
| :-------- | :---------- |
| `WORKSPACE_INSTANCE` | The Databricks workspace instance URL host, for example `000-0000000000000.cloud.databricks.com`. |
| `CREDENTIALS` | OAuth credentials used when invoking Databricks services. |

#### OAuth authentication parameters

| Parameter | Description |
| :-------- | :---------- |
| `OAUTH_CLIENT_ID` | The OAuth client ID for Databricks authentication. |
| `OAUTH_CLIENT_SECRET` | The OAuth client secret for Databricks authentication. |
| `OAUTH_SCOPE` | Optional OAuth scope for authentication. |
| `OAUTH_SERVER_URL` | Optional OAuth server URL for authentication. |

## Examples

### Create a Databricks location

```sql
CREATE LOCATION my_databricks_location WITH
  SOURCE = DATABRICKS
  WORKSPACE_INSTANCE = '000-0000000000000.cloud.databricks.com'
  CREDENTIALS = (
    OAUTH_CLIENT_ID = '00000000-0000-0000-0000-000000000000'
    OAUTH_CLIENT_SECRET = '********'
  )
  DESCRIPTION = 'Credentials for invoking Databricks serving endpoints';
```

<Note>
To use this location, pass its name as the `<location>` argument to [`DATABRICKS_AI_QUERY`](/reference-sql/functions-reference/ai/databricks-ai-query).
</Note>
