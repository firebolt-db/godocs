Firebolt Core is a free, self-hosted edition of the Firebolt high-performance distributed query engine, designed to power the data infrastructure behind today's most demanding applications.

Head to [Introduction](/firebolt-core/firebolt-core-introduction) to get an overview of Firebolt Core, or directly to [Get Started](/firebolt-core/firebolt-core-get-started) if you're eager to run your first query.
