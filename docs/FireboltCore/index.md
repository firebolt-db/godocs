# Firebolt Core

Firebolt Core is a free, self-hosted edition of the Firebolt high-performance distributed query engine, designed to power the data infrastructure behind today's most demanding applications.

Head to [Introduction](./firebolt-core-introduction.md) to get an overview of Firebolt Core, or directly to [Get Started](./firebolt-core-get-started.md) if you're eager to run your first query.
